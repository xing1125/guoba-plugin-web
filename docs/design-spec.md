# 云崽管理后台 · 设计规范与组件标准

> 参考基准：[《超全面 B 端设计规范总结》](https://www.woshipm.com/pd/5175891.html)（设计小余）
> 本文是**本后台的落地版**：原文给的是通用 B 端组件盘点，这里把它收敛成可执行的标准，
> 并补上一条明确的产品判断——**详情/记录/确认一律居中弹窗，不用右侧抽屉**。
>
> 适用：`guoba-web-fork/src/views/guoba/**`。新增页面、改版页面均按此检查。

---

## 0. 一条硬规则：不用侧面抽屉

原文提到「需要参考页面信息填写表单时，抽屉更合理」（左边看数据、右边填表单）。
但我们后台的实际使用场景是**看数据、做少量确认**，不是边看边填一整张长表单，抽屉带来三个具体问题：

1. **视线要横移**：从表格行到右侧抽屉，眼睛和鼠标都要跨过半个屏幕；1920 下抽屉贴在右边缘，注意力被拉到角落。
2. **空间被浪费**：抽屉宽度受限于右侧滑出，内容多为「身份 + 指标 + 图表」，横排两栏在抽屉里只能竖着堆，要滚。
3. **交互割裂**：点行 → 滑出 → 内容二次加载 → 关闭 → 再点下一行，每一轮都要重新定位；弹窗在视野中央，关闭后视线原地回到列表。

因此：

| 场景 | 用什么 | 说明 |
| --- | --- | --- |
| 单条数据详情（用户 / 群 / 账号 / 键 / 聊天记录 / 签到明细） | **居中弹窗** | 两栏：左身份与指标、右图表/明细 |
| 记录型列表（备份、删除记录、登录日志） | **居中弹窗** | 表格 + 分页，高度由 body 滚动控制 |
| 确认（危险操作、批量清理） | **居中弹窗**（`GConfirmModal`） | 主按钮用危险色 |
| 轻表单（编辑 CK、改密、建用户） | **居中弹窗**（`GFormModal`） | 字段 ≤ 8 个 |
| 例外：需要边看左侧页面边填一张很长的表单 | 抽屉 | 当前后台**暂无**此场景；出现时须在 PR 说明理由 |

新增代码里出现 `ant-design-vue` 的 `Drawer` 即视为不合规（插件自带的第三方配置页除外）。

## 1. UI 规范

### 1.1 色彩

| 类别 | 用途 | 变量 |
| --- | --- | --- |
| 品牌/主色 | 主按钮、选中态、链接、图表主线 | `--g-blue`（深色 `--g-cyan`） |
| 辅助色 | 成功 `--g-green`、警告 `--g-gold`/`--g-amber`、危险 `--g-rose`/`--g-red`、信息 `--g-violet` | 同上 |
| 中性色 | 文本 `--g-text` / 次级 `--g-text-sub` / 弱化 `--g-text-mute`；卡片 `--g-card-bg` / 内嵌 `--g-card-bg-soft`；描边 `--g-card-border`；分割 `--g-track`/`--g-grid` | 同上 |
| 其它色 | 图表分类、游戏主题色（`GameIcon` / `GAME_META` 的 `from→to`） | 局部定义，不新增全局变量 |

约定：
- 中性色**同一色相 + 透明度**表达层级，不引入第二种灰。
- 深浅色只换变量值，不写死颜色；确需写死（如头像渐变）必须保证两种主题下对比度 ≥ 4.5:1。
- 涨红跌绿（A 股习惯）只用于金融类视图；本后台不用红绿表达增减。

### 1.2 字体

- 中文：系统默认（苹方 / 思源黑体 / 微软雅黑）；英文与数字：`ui-monospace` 只用于 ID、键名、时间戳等需要对齐比对的字段。
- 字号阶梯：`10 / 11 / 11.5 / 12 / 12.5 / 13 / 14 / 15.5 / 16 / 18 / 21 / 23 / 27`，**正文 12.5–14，标题 15.5–16，KPI 数字 21–27**。
- 行高 = 字号 + 8（12→20、14→22）；表格行高 40（表头）/ 48（中号行）。
- 数字一律 `font-variant-numeric: tabular-nums`，保证列对齐。

### 1.3 布局

- 内容区左右最小留白 16，卡片间距 14，卡片内边距 14–16。
- 栅格：24 栅格思路，实现上用 CSS Grid；常用断点 `1180px`（侧栏 + 主区改单列）、`900px`（弹窗两栏改单列）。
- 适配目标分辨率 1920 / 1440 / 1366；页面横向滚动只允许出现在表格内部。

### 1.4 图标

- 统一 `Icon` 组件 + iconify（`ant-design:*`），尺寸 11 / 13 / 14 / 19；默认 13。
- 图标只做分类与点缀，**不承担唯一语义**，旁边必须有文字。

## 2. 组件规范

### 2.1 按钮

- 五种：主按钮 `type="primary"` / 默认 / 虚线（新增行）/ 文本 / 链接（表格行内操作）。
- **一个操作区域只允许一个主按钮**；工具栏里「查询」可为主按钮，其余用默认。
- 危险操作主按钮加 `danger`，且必须经 `GConfirmModal` 二次确认。
- 表格行内最多 3 个文字按钮，超出收进「更多」。

### 2.2 表格

- 表头：11.5px、`--g-text-mute`、`--g-card-bg-soft` 底、下边框 1px；去掉 antd 默认竖分割线。
- 行 hover 用 `--g-hover`；斑马纹仅用于 ≥ 50 行的密集表。
- 主标识列固定左侧，操作列固定右侧；时间列统一格式化（`YYYY-MM-DD HH:mm`），不直接渲染 ISO 字符串。
- 空态用 `GEmpty`，文案说明「为什么空 + 怎么产生数据」，不要只写「暂无数据」。

### 2.3 标签页

- 横向标签用 `.gm-seg` 分段控件（`is-active` 态），**切换必须走函数**（`switchTab(k)`），不要在模板里直接赋值，否则首次进入该页签数据为空。
- 页签数量 2–4；超过 4 个改用纵向导航（如账号页左侧游戏栏）。

### 2.4 分页

- 默认 pageSize 20，可选 10/20/50/100；显示总数文案。
- 页码数控制在 5 个以内（antd 默认行为），不额外定制。

### 2.5 表单与控件

**控件不再直接用 antd 默认样式**，统一由 `design/guoba-controls.less` 接管（light / dark 一套变量）。

| 项 | 规范 |
| --- | --- |
| 高度 | `sm 28` / 默认 `32` / `lg 38` |
| 圆角 | 默认 10，`sm` 8 |
| 底色 | `--g-card-bg-soft`；聚焦时 `--g-card-bg` |
| 描边 | 常态 `--g-card-border`，hover `--g-card-border-strong`，聚焦 `--g-blue` + `0 0 0 3px --g-blue-soft` |
| 占位符 | `--g-text-mute`，别写「请输入」这类空话，直接说搜索什么 |
| 前缀图标 | 常态 mute，聚焦转 `--g-blue` |
| 清除按钮 | 圆形 15px，底 `--g-chip-bg`，hover 加深 |
| 禁用 | 底 `--g-hover`，文字 mute，`cursor: not-allowed` |
| 错误 | 描边 `--g-red`，聚焦环 `--g-gold-soft`；错误文案紧贴控件下方 |
| 下拉面板 | 圆角 12、内边距 6、双层阴影；选项高 32 / 圆角 8；选中项主色文字 + `--g-blue-soft` 底 |
| 空态 | 不出现英文 `No Data`，统一「暂无可选项 / 没有匹配项」+ 图标 |

**组件（`_shared/form/`）**

| 组件 | 用途 | 要点 |
| --- | --- | --- |
| `GSearch` | 列表页搜索框 | 前缀搜索图标、清除即回收结果、回车触发、`loading` 转圈 |
| `GSelect` | 选择器 | 默认 allowClear + 中文空态；`width` 一次说清，不再写 `style="width"` |
| `GField` | 表单行 | label + 必填星号 + 右侧 `extra` + `hint` / `error` 三段式 |
| `GToolbar` | 筛选条 | 左筛选右操作，8px 节奏，窄屏自动换行 |
| `GSegmented` | 分段切换 | 收编 `.gm-seg`；`options` 带 `count` / `disabled`，有 `aria-selected` |

- 弹窗内字段少 → `GField` 上下结构；页面内宽表单 → 左右结构（label 宽 120，右对齐）。
- 必填标记、错误提示紧贴字段下方；提交失败在字段处标红，不用全局 toast 顶替。
- 筛选控件放在面板头 `.gm-panel__head` 右侧时用 `.toolbar`（全局类，组内 8px 节奏）；
  页面级独立筛选条用 `<GToolbar>`（左右分栏）。

> **权重约定（改样式前必读）**：ant-design-vue 3.x 用 cssinjs 在运行时注入 `<style>`，
> 位置在静态 CSS 之后；深色还多一份被 vite-plugin-theme 抽出的 antd 暗色表，
> 选择器带 `html[data-theme='dark']` 前缀（0,2,1）。因此 `guoba-controls.less` 里所有规则
> 统一挂在 `:root:root` 下（单类规则变成 0,3,0），否则会静默退回 antd 默认圆角 2 / 2px 聚焦环。
> 新增控件规则请一并放进这个 `:root:root` 块，不要另起顶层选择器。


### 2.6 气泡卡片 / 警告提示

- 表格内容溢出用 `Tooltip` 显示全文；字段含义用「?」图标 + `Tooltip`。
- 警告提示四态：成功（绿）/ 信息（蓝）/ 警告（金）/ 错误（红），单条提示 ≤ 2 行，超出行内折叠。
- 说明性黄条（如「演示数据」）用 `--g-gold-soft` 描边，不铺满底色。

### 2.7 空态与骨架

- 首次加载用骨架屏（`g-skeleton`），不用转圈遮罩整页。
- 刷新时保留旧数据 + 按钮 loading，避免页面闪白。

## 3. 弹窗规范（核心）

### 3.1 尺寸

| 档位 | 宽度 | 用途 |
| --- | --- | --- |
| `sm` | 440 | 确认、单行提示 |
| `md` | 600 | 轻表单（≤ 6 字段）、短记录 |
| `lg` | 760 | 记录列表（备份/删除记录）、群详情 |
| `xl` | 920 | 两栏详情（用户/账号/键/聊天记录）、带图表 |

- 位置：**垂直水平居中**（`centered`）。
- 高度：`body` 独立滚动，默认上限 `62vh`；两栏详情可放到 `64vh`。头部与底部**常驻不滚**。
- 宽度不超过视口 92%，小屏（< 900）两栏自动改单栏。

### 3.2 结构与视觉

```
┌──────────────────────────────────────────┐
│ EYEBROW（大写 10px，弱化）          [×]  │  head：18/20 padding，底边 1px
│ 标题 15.5px 650                          │
│ 副标题（等宽 11.5px，ID/路径）           │
├──────────────────────────────────────────┤
│ body：16/20 padding，独立滚动            │
├──────────────────────────────────────────┤
│                        [次要] [主按钮]   │  footer：右对齐，内嵌底色 + 上边框
└──────────────────────────────────────────┘
```

- 圆角 16，描边 `--g-card-border`，阴影 `0 24px 64px -20px rgb(8 20 34 / 42%)`。
- 关闭：右上角 26×26 图标按钮 + `ESC`；**遮罩点击默认不关闭**（防误触丢输入）。
- `destroyOnClose`：含图表/大表格的弹窗开启，避免图表尺寸计算在隐藏容器里出错。

### 3.3 交互规则

1. 打开即有内容：详情数据在点击行时同步传给弹窗（先用列表行数据兜底渲染），再异步补全，**不要空白等待**。
2. 关闭后焦点回到触发行（列表不重排、不跳页）。
3. 危险操作：确认弹窗主按钮 `danger`，文案写清「对象 + 后果 + 是否可恢复」。
4. 弹窗内不做二级弹窗跳转；确需二次确认时，用 `GConfirmModal` 叠加并保留第一层。
5. 同一页面同类详情只允许一个弹窗实例，切换数据时复用（改数据不改实例）。

### 3.4 组件

| 组件 | 文件 | 用途 |
| --- | --- | --- |
| `GModal` | `_shared/dialog/GModal.vue` | 通用居中弹窗（详情/记录/任意内容），`size` 四档 |
| `GConfirmModal` | `_shared/dialog/GConfirmModal.vue` | 确认类，`danger` 控制主按钮颜色 |
| `GFormModal` | `_shared/dialog/GFormModal.vue` | 由 schema 生成的轻表单 |

```vue
<GModal
  v-model:visible="open"
  eyebrow="USER PROFILE"
  title="用户详情"
  :subtitle="uid"
  size="xl"
  body-height="64vh"
>
  <div class="dm">
    <aside class="dm__side"><!-- 身份 + 指标 --></aside>
    <div class="dm__main"><!-- 图表 + 明细 --></div>
  </div>

  <template #footer>
    <Button @click="open = false">关闭</Button>
    <Button type="primary" @click="save">保存</Button>
  </template>
</GModal>
```

### 3.5 弹窗内容排版类（`dm-*`）

弹窗里的内容不许各页自己发明类名。指标条、区块、弱化说明统一用
`_shared/dialog/dm.less`，在页面 `<style scoped lang="less">` 顶部一行引入：

```less
@import '../_shared/dialog/dm.less';
```

| 类名 | 作用 | 关键数值 |
| --- | --- | --- |
| `.dm-stats` | 指标条（默认 3 列，`12px 10px` 间距） | 有 `--cols2` / `--cols3` / `--panel`（卡片底+描边+12 圆角）/ `--divider`（偶数列左分隔线） |
| `.dm-stat__label` | 指标名 | 11px / `--g-text-mute` / 单行省略 |
| `.dm-stat__value` | 指标值 | 15px / 650 / `tabular-nums` / 单行省略 |
| `.dm-block` | 弹窗内区块（不设外边距） | 间距交给容器 `gap` 或页面局部规则 |
| `.dm-block__head` | 区块头（左标题、右 meta） | 下内边 8 + 下边框 1px |
| `.dm-block__title` | 区块标题 | 12.5px / 600 / `letter-spacing .01em` |
| `.dm-block__meta` | 区块右侧补充说明（如「12 天有记录」） | 11px / `--g-text-mute` |
| `.dm-hint` | 区块或面板下方说明 | 11px / 行高 1.72 |

- 两栏详情：左栏固定 `286px`（`.dm` 的 `grid-template-columns`），右栏 `minmax(0,1fr)`；
  `< 900px` 自动单栏。
- 键值信息（键名/类型/大小/TTL）用 `<dl class="dm-meta">` + `.dm-meta__item`，
  长键名加 `--wide` 独占一行并 `word-break: break-all`。
- **弹窗内图表必须等容器可见后再 `setOptions`**：`useECharts` 现在对「容器未挂载」
  做 6 次 / 40ms 重试，主题切换时不会再把已 dispose 的实例留在引用里
  （旧行为会让深色模式下弹窗图表永久空白）。

## 4. 自检清单（提交前逐条过）

- [ ] 没有新增 `Drawer`；详情/记录/确认全部居中弹窗
- [ ] 主按钮唯一，危险操作有二次确认
- [ ] 颜色只用 `--g-*` 变量，深浅两套都截图看过
- [ ] 数字列 `tabular-nums`，时间列已格式化
- [ ] 空态有解释文案，首次加载有骨架
- [ ] 弹窗 body 可滚，头尾常驻；ESC 可关；遮罩点击不关
- [ ] 弹窗内指标/区块用的是 `dm-*` 共享类，没有自己造 `.detail-stats` / `.block-title`
- [ ] 深浅两套下弹窗内的图表都真的画出来了（切主题后再开弹窗必须复验）
